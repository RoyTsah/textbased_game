# 🎮 DOOM ISLAND

Ein kleines textbasiertes Minigame im klassischen Retro-Stil.

Das Spiel wird direkt in der Windows-Kommandozeile (CMD) ausgeführt und nutzt ASCII-Art zur Darstellung. Eine grafische Benutzeroberfläche (GUI) ist nicht vorhanden.

---

## 📖 Projektbeschreibung

DOOM ISLAND ist ein kleines Konsolenspiel, das den Charme klassischer Terminal- und Textspiele aufgreift. Die gesamte Interaktion erfolgt über Tastatureingaben in der Kommandozeile.

Das Projekt entstand als Lernprojekt, um praktische Erfahrungen in der Anwendungsentwicklung zu sammeln und grundlegende Programmierkonzepte anzuwenden.

---

## ✨ Features

- Ausführung direkt in der Windows-CMD
- ASCII-Art zur visuellen Darstellung
- Tastaturbasierte Steuerung
- Einfaches Spielsystem
- Retro-Look klassischer Konsolenspiele
- Keine Installation erforderlich

---

## 🛠 Verwendete Technologien

- Python
- Pyfiglet
- ASCII-Art

---

## 🚀 Spiel starten

1. Die bereitgestellte `.exe`-Datei herunterladen.
2. Die Datei per Doppelklick starten.
3. Das Konsolenfenster öffnet sich automatisch.

Es ist keine Installation erforderlich.
